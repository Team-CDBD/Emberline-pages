# Emberline Web

`정착산업: Emberline`의 플레이 가능한 Godot Web Export 저장소입니다.

- 플레이: <https://team-cdbd.github.io/Emberline-pages/>
- 전체 소스와 커밋 기록: <https://github.com/Team-CDBD/Emberline> (비공개, 초대된 심사 계정만 열람)
- 이 배포의 기준 소스 커밋: [`cfec467`](https://github.com/Team-CDBD/Emberline/commit/cfec467632e77dd2e780e31237c9e49a817e1815)
- 이 배포의 게임 파일 커밋: [`9161780`](https://github.com/Team-CDBD/Emberline-pages/commit/9161780ddb47a7c8ee232a2c5fcb0112f4c96a77)

이 공개 저장소는 심사자가 로그인 없이 브라우저에서 플레이할 수 있도록 Web Export 결과만 보관합니다. 전체 Godot 프로젝트, 테스트와 개발 이력은 비공개 소스 저장소에 있습니다. 이 저장소의 게임 파일은 배포 산출물이므로 직접 수정하지 않습니다.
